# fspy Linux interception research

These notes record experiments and decisions for running fspy code after a
Linux `exec` has committed but before the new program executes its first
instruction. They are experimental references, not production guarantees.

| Note                                                                      | Purpose                                                                                                                                                                                   |
| ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Invalid ELF exec outcomes](linux-invalid-elf-exec-outcomes.md)           | Separates malformed ELF cases that return errno, force `SIGSEGV` after exec's point of no return, or fault only after the kernel has accepted the new image.                              |
| [Exec pre-entry alternatives](exec-preentry-alternatives.md)              | Ranks no-sudo mechanisms, documents the ELF-loader prototype and performance measurements, and records compatibility boundaries.                                                          |
| [Ptrace injection prototype](../crates/inject_demo/README.md)             | Describes the current ptrace plus in-process `SIGSYS` proof of concept.                                                                                                                   |
| [Ptrace environment compatibility](ptrace-environment-compatibility.md)   | Tests descendant ptrace under Docker, Yama, seccomp, capabilities, namespaces, dumpability, and privilege-changing exec, then maps the result to CI, Kubernetes, WSL2, and AI sandboxes.  |
| [Kubernetes ptrace results](ptrace-kubernetes-results.md)                 | Directly tests omitted, RuntimeDefault, Restricted, explicit-deny, and shared-process-namespace sidecar cases on kind/containerd/runc.                                                    |
| [gVisor ptrace results](gvisor-ptrace-results.md)                         | Tests runsc permissions and injection primitives, the explicit-trap replacement for ARM64 single-step, and the ARM64 seccomp signal-frame drift behind the x86-64/ARM64 end-to-end split. |
| [Rootless-container ptrace results](rootless-container-ptrace-results.md) | Directly tests rootless Podman and Docker userns-remap with stock seccomp, unprivileged identities, and the then-current single-step injector snapshot.                                   |
| [AI sandbox ptrace results](ai-sandbox-ptrace-results.md)                 | Directly compares descendant ptrace in OpenAI Codex Cloud and GitHub Copilot coding agent, including the Codex `process_vm_*` gap.                                                        |
| [Copilot coding-agent capture](copilot-coding-agent-ptrace-results.md)    | Preserves the complete environment and shared-probe output generated inside the Copilot coding-agent session.                                                                             |
| [WSL2 ptrace results](ptrace-wsl2-results.md)                             | Imports Ubuntu under real WSL2 without reboot, then directly runs the unprivileged descendant probe and current injector.                                                                 |
| [Hardened hosted/WSL2/gVisor rerun](ptrace-strict-rerun-results.md)       | Reruns the exit-enforcing probe and current explicit-trap injector on hosted Ubuntu, default containers, imported WSL2, and x86-64 runsc.                                                 |

## Reproduction artifacts

| Artifact                                                                                                                                              | Purpose                                                                                                                                          |
| ----------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`ptrace-environment-probe.c`](ptrace-environment-probe.c)                                                                                            | Exercises descendant permissions, register access, ptrace word I/O, process-VM I/O, Yama relationships, dumpability, and setuid exec behavior.   |
| [`ptrace-exec-injection-primitives-probe.c`](ptrace-exec-injection-primitives-probe.c)                                                                | Exercises `TRACEEXEC`, the exec event, register/code mutation, remote `mmap`, an explicit trap, restoration, and detach on x86-64/AArch64.       |
| [`gvisor-seccomp-trap-arg0-probe.c`](gvisor-seccomp-trap-arg0-probe.c)                                                                                | Compares native Linux and gVisor preservation of syscall argument zero in an AArch64 `SECCOMP_RET_TRAP` signal frame.                            |
| [`ptrace-deny-seccomp.json`](ptrace-deny-seccomp.json)                                                                                                | Docker/Kubernetes seccomp control that explicitly denies ptrace and process-VM syscalls.                                                         |
| [`pr-set-ptracer-deny-seccomp.json`](pr-set-ptracer-deny-seccomp.json)                                                                                | Docker seccomp control that denies only `prctl(PR_SET_PTRACER, ...)` to exercise graceful reporting.                                             |
| [`ptrace-docker-userns-daemon.json`](ptrace-docker-userns-daemon.json)                                                                                | Minimal daemon setting needed by the isolated Docker `userns-remap` experiment. Use only in a disposable VM or dedicated host network namespace. |
| [`ptrace-kubernetes-sidecar-probe.c`](ptrace-kubernetes-sidecar-probe.c)                                                                              | Separates shared PID visibility, ancestry, `PR_SET_PTRACER`, and credential checks across containers.                                            |
| [`ptrace-kubernetes-sidecar.Dockerfile`](ptrace-kubernetes-sidecar.Dockerfile) and [`ptrace-kubernetes-sidecar.yaml`](ptrace-kubernetes-sidecar.yaml) | Build and run the three Restricted shared-process-namespace sidecar cases.                                                                       |
| [`ptrace-wsl2-experiment.yml`](ptrace-wsl2-experiment.yml)                                                                                            | Recreates the hosted Windows workflow that imports a pinned Ubuntu image as WSL2, runs both probes, and unregisters it.                          |
| [`ptrace-strict-hosted-wsl-experiment.yml`](ptrace-strict-hosted-wsl-experiment.yml)                                                                  | Recreates the hardened hosted Ubuntu, Docker, default job-container, denial, and imported WSL2 matrix.                                           |
| [`ptrace-gvisor-x86-experiment.yml`](ptrace-gvisor-x86-experiment.yml)                                                                                | Installs a pinned x86-64 runsc release and reruns the hardened probe plus current explicit-trap injector.                                        |
